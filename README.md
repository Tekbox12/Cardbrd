
# CardBrd12

12 key macro pad built using ergogen v4

## Features

- 12 keys (4 rows 3 columns
- rotary encoder with click
- reset button

## Materials
* 1x Pro micro
* 1x ec11 rotary encoder
* 1x reset switch (smd, 4 pin, flat)
* 12 1N4148 Switches (smd or through hole)
* 12 any(i think) 5 pin mx switches
