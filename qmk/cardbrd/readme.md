# Cardbrd

![cardbrd](image here imgur)

A 12 key (4x3) macro pad built using ergogen v4

* Keyboard Maintainer: [Tekbox12](https://github.com/Tekbox12)
* Hardware Supported: Cardbrd pcb
* Hardware Availability: Cardbrd pcb

Make example for this keyboard (after setting up your build environment):

    make handwired/Tekbox12/cardbrd:default



See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Features

- 12 keys (4 rows 3 columns)
- rotary encoder with click
- reset button

## Bootloader

Enter the bootloader in 3 ways:
* **Physical reset button**: Press the button below the pro micro
